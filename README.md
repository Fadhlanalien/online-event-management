# Online Event Management System

## Description
A Flask-based web application for managing online events.

## Technologies
- Python
- Flask
- HTML
- CSS
- JavaScript
- SQLite

## Installation
1. Clone the repository.
2. Create and activate a virtual environment.
3. Install dependencies:

```bash
pip install -r requirements.txt
```

## Run the application

```bash
python app.py
```

or

```bash
python3 app.py
```

## Features
- User registration
- User login
- Event management
- Event registration
- Profile update
